# Forest Rush C++

Original 3D portrait endless runner written in C++17 with raylib 6.0.

- Rounded articulated runner, no cube/block character parts.
- Dense stylized forest, dirt trail, layered trees and organic props.
- Restrained exposure: no HDR bloom or white wash.
- 4x MSAA hint, 60 fps target, arm64 Android build.

Controls: swipe left/right to change lane, up to jump, down to slide. Keyboard arrows/WASD/Space work for desktop testing.
